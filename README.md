# Rock Paper Scissor Game ✂️

Day 4 of 100 Days of Code Challenge - Python

## About
A simple fun game where you play Rock Paper Scissors against the computer. Built using Python's random module.

## How to Play
- Choose 0 for Rock, 1 for Paper, 2 for Scissors
- Computer will also choose randomly
- Winner is decided!

## Tech Used
- Python
- Random Module
- If-Else Conditions
